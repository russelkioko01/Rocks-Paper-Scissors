
✊ Rock Paper Scissors Web App

📌 About the Project
Rock Paper Scissors is an interactive web application that allows users to play the classic Rock Paper Scissors game against the computer. The app provides a simple, user-friendly interface and displays the results of each round instantly.

This project demonstrates my understanding of web development fundamentals and JavaScript programming logic.

🎮 Features
- Interactive Rock, Paper, and Scissors choices.
- Randomized computer selections.
- Automatic winner determination.
- Instant display of game results.
- Score tracking for the player and computer.
- Simple and user-friendly interface.

🛠️ Technologies Used
- HTML5 – Structures the web page.
- CSS3 – Styles the interface and improves the user experience.
- JavaScript – Implements the game logic and score tracking.

🚀 How to Run the Project
1. Clone or download this repository.
2. Open the project folder on your computer.
3. Open `index.html` in your web browser.
4. Select Rock, Paper, or Scissors to start playing.

📂 Project Structure

rock-paper-scissors/

📖 How to Play
- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- If both the player and computer choose the same option, the round ends in a draw.
